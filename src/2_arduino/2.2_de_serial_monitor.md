# 2.2 De Serial Monitor

Een microcontroller heeft geen scherm. Wanneer een sketch niet doet wat
verwacht wordt, is er dus op het eerste zicht geen enkele manier om te zien
waarom. De **Serial Monitor** lost dat op: het is een venster in de IDE dat de
tekst toont die het board via de USB-verbinding (een seriële verbinding, ook
wel **UART** genoemd) naar de computer stuurt. Omgekeerd kan de computer ook
tekst naar het board sturen.

Voor de meeste studenten is dit het belangrijkste hulpmiddel om te
**debuggen**: op strategische plaatsen in de code wordt een boodschap
uitgeprint, zodat zichtbaar wordt welke waarden variabelen hebben en welke
delen van de code effectief uitgevoerd worden.

## 2.2.1 Tekst naar de computer sturen

```cpp
int loop_counter = 0;

void setup() {
  Serial.begin(115200);  // start serial communication at 115200 baud
}

void loop() {
  Serial.print("loop iteration: ");
  Serial.println(loop_counter);  // println adds a newline at the end
  loop_counter++;
  delay(1000);
}
```

- `Serial.begin(115200)` start de seriële communicatie. Het getal is de
  **baudrate**: de snelheid van de verbinding, uitgedrukt in symbolen per
  seconde.
- `Serial.print()` stuurt tekst of een waarde door, `Serial.println()` doet
  hetzelfde en voegt er een nieuwe regel aan toe.

De Serial Monitor wordt geopend via het icoontje rechtsboven in de IDE, of via
*Tools > Serial Monitor*.

> **Let op:** de baudrate in de code (`Serial.begin(...)`) en de baudrate
> in de Serial Monitor (dropdown rechtsonder in het paneel) moeten
> **identiek** zijn. Bij een verschil verschijnen er onleesbare tekens
> in plaats van tekst. Klassieke Arduino-voorbeelden gebruiken
> vaak 9600, bij ESP32-boards is 115200 de gangbare waarde.

## 2.2.2 Tekst naar het board sturen

Via het invoerveld bovenaan de Serial Monitor kan ook tekst naar het board
gestuurd worden. In de sketch wordt die binnengelezen met `Serial.available()`
(zijn er nieuwe tekens binnengekomen?) en `Serial.read()` (lees één teken):

```cpp
void setup() {
  Serial.begin(115200);
}

void loop() {
  if (Serial.available() > 0) {
    char received_char = Serial.read();
    Serial.print("received: ");
    Serial.println(received_char);
  }
}
```

Zo kan bijvoorbeeld een LED bediend worden met commando's vanaf het
toetsenbord, zonder dat er al een fysieke knop aangesloten moet worden.

## 2.2.3 De Serial Plotter

Naast de Serial Monitor bestaat er ook een **Serial Plotter**. Die tekent
numerieke waarden die via `Serial.println()` verstuurd worden als een grafiek
in de tijd. Dit is bijzonder handig om het verloop van een sensorwaarde te
bekijken, zoals een analoge sensor die uitgelezen wordt in latere hoofdstukken.
